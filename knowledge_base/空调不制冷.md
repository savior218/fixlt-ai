# 空调不制冷 · 知识条目

> 知识库条目结构（KB-001）：设备类型 / 现象 / 可能原因 / 风险等级 / 来源 / 更新时间。
> 优先收录品牌官方说明书、官方故障代码资料与经核验的公开技术资料。

- 设备类型：空调（ac）
- 品牌 / 型号：通用
- 现象：开机运行但制冷效果差 / 完全不制冷
- 风险等级：低（基础检查范围）
- 来源：通用维修知识整理（待官方资料核验）
- 更新时间：2026-11-16

## 可能原因（按常见程度）

1. 滤网积灰导致出风量下降 —— 基础检查：断电取出滤网查看积尘程度
2. 模式 / 温度设置不当 —— 基础检查：确认为制冷模式，设定温度低于室温
3. 室外机散热不良（遮挡、积灰）—— 基础检查：目视检查外机周围是否有遮挡
4. 制冷剂不足或系统故障 —— 需专业设备检测压力，不建议用户自行判断

## 安全边界

- 用户可执行：拔插头断电后清洗滤网、检查遥控器设置、目视检查外机
- 用户不可执行：拆卸外机外壳、自行加氟、触碰制冷剂管路（属高风险操作，SAFE-001 拦截项）
