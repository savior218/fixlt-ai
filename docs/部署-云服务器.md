# 云服务器部署指南（Docker Compose）

> 适用于任意带 Docker 的 Linux 云服务器（阿里云 / 腾讯云 / 华为云等）。
> 部署完成后前后端同源：`http://<服务器公网IP>:8000` 即整站（含登录注册）。

## 1. 服务器准备（只做一次）

```bash
# Ubuntu/Debian 装 Docker（已装可跳过）
curl -fsSL https://get.docker.com | sh
sudo systemctl enable --now docker

# CentOS/openEuler
# sudo yum install -y docker-ce docker-compose-plugin && sudo systemctl enable --now docker
```

在云厂商控制台的**安全组 / 防火墙**放行 TCP 端口 `8000`（对外访问入口）。

## 2. 拉代码并启动

```bash
git clone https://gitee.com/savior218/fix-ai.git fixitai
cd fixitai

# （可选）配置真实 AI 诊断：填入智谱 API Key，不填则自动回退本地 Mock
cp .env.example .env
vi .env        # FIXITAI_AI_API_KEY=你的key

# 构建并后台启动（首次构建约 3-5 分钟）
docker compose up -d --build
```

## 3. 验证与访问

```bash
curl http://127.0.0.1:8000/api/health    # 返回 ok 即成功
```

浏览器打开 `http://<服务器公网IP>:8000` → 登录页 → 演示账号 `demo` / `123456`。

## 4. 日常运维

```bash
docker compose logs -f          # 看日志
docker compose restart          # 重启
docker compose up -d --build    # 拉新代码后更新（git pull 后执行）
docker compose down             # 停止（数据在 fixitai_data 卷中，不会丢）
```

## 5. 更换端口

编辑 `.env` 加一行 `FIXITAI_PORT=80`（用 80 端口可直接访问不带 :8000），然后 `docker compose up -d`。

## 常见问题

- **端口被占用**：换 `FIXITAI_PORT`，或 `sudo lsof -i:8000` 排查占用进程。
- **AI 诊断返回模板内容**：未配置 `FIXITAI_AI_API_KEY`，属预期回退行为。
- **忘记 demo 密码**：`docker compose down && docker volume rm fixitai_fixitai_data && docker compose up -d`（清库重来）。
