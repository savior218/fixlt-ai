## 三、本轮完成内容（V3 之后）

### 3.1 法务文档与信息架构

- 用户协议、隐私政策、使用规范、版权说明改为独立整页版式，包含文档目录与相互链接，未登录也可公开查看。
- 页脚「安全守护 / 使用规范」等入口指向独立页面，避免弹窗式阅读体验。
- 登录页品牌改用新 Logo，与应用内字标统一；未登录访问内页先进入登录页并保留返回地址，登录后 7 天免登录。
- 点击当前页导航项回到页面顶部，平滑滚动并尊重系统「减少动画」设置。
- 顶栏品牌随侧栏展开/收起切换，修复合并时丢失的侧栏暖色氛围与分割线。

### 3.2 隐私与权限

- 新增 `MediaPermission` 前置授权组件：访问照片、麦克风前先弹窗说明用途，用户允许后才继续下一步。
- 已接入 AI 诊断、动态问诊、智能报修、设置等需要媒体权限的页面，避免浏览器权限弹窗突然出现。

### 3.3 AI 问诊升级

- 诊断页由固定步骤问诊改为聊天式自由多轮对话：用户可直接输入问题，AI 结合设备、描述、照片与完整上下文回复，并自主判断信息是否足够。
- 支持游客上传照片并由视觉模型识别，照片随用户消息显示在对话气泡内；AI 看过照片后保留在上下文中，不重复上传。
- 诊断报告改为按需生成：对话信息足够后，用户可主动生成完整报告；AI 失败时保留全部对话并提示重试，不静默回退模板。
- 默认文本模型切换为 `glm-4-air`，视觉模型切换为 `glm-4v`，提升截图识别与多轮对话稳定性。
- 原结构化动态追问能力保留，仍覆盖空调「不制冷 / 制冷效果变差」场景。

### 3.4 三端一致性与移动端修复

- 修复首页、智能报修、工单详情、设置页、顶栏在手机/平板/桌面下的一致性问题。
- 新增 `utils/clipboard.ts`：优先使用异步剪贴板 API，在非安全上下文或旧版安卓 / 微信内置浏览器中回退到 `execCommand`，保证复制功能在三端可用。
- 调整 `layout.css` 与相关页面布局，修复移动端溢出、按钮不可达等问题。

### 3.5 视觉细节

- 首页设备图增加投影增强立体感，保持暖纸 Claude 风格统一。
- 顶栏、侧栏、按钮、弹窗等同类控件继续保持右缘对齐规范。

## 四、产品能力快照

### 4.1 页面与组件

- **22 个页面**：首页、AI 诊断、动态问诊、诊断结果、诊断报告、设备列表/详情、智能报修、工单详情、维修历史、维修档案、个人设置、数据管理、登录、安全守护、关于修必达、隐私政策、用户协议、使用规范、版权说明、UI Kit、404 等。
- **32 个公共组件**：TopBar、SidebarNav、MobileNavDrawer、ModalDialog、SourceBadge、NotificationPopup、SafetyBanner、LegalPage、MediaPermission 等。

### 4.2 核心业务闭环

进入诊断 → 描述故障 / 上传照片 → AI 多轮问诊 → 结果与报告 → 保存维修档案 → 一键带入智能报修 → 工单状态跟踪。

### 4.3 AI 与安全

- 诊断页为聊天式自由多轮对话：用户直接输入，AI 结合设备、描述、照片与完整历史回复，自主判断何时信息足够；报告按需生成。
- 文本模型默认 `glm-4-air`，视觉模型默认 `glm-4v`，OpenAI 兼容协议，默认 60s 超时。
- 支持游客上传故障照片并由视觉模型分析，照片随消息显示，识别后保留在上下文中。
- 结构化动态追问保留，首版覆盖空调「不制冷 / 制冷效果变差」场景。
- 安全关键词拦截由前端本地规则与后端规则分别执行，LLM 不参与风险判定；后端对高风险请求直接 409 且不调用模型。
- 诊断来源可追溯：真实 AI / 模板演示 / 来源未记录，AI 失败不伪装成功，模板演示需用户主动选择。

### 4.4 账号与数据

- 真实注册 / 登录 / 退出，HttpOnly Cookie 会话 + CSRF + 限流，密码 bcrypt 哈希。
- 设备、诊断记录、维修档案、报修工单按账号隔离；支持本机历史记录导入。
- 头像上传、资料修改、新消息提醒与免打扰开关。

### 4.5 关怀与无障碍

- 长辈关怀模式：同一份诊断事实生成标准 / 长辈两套表达，只改变文案风格，不改变结论、原因排序与风险判断。
- 语音朗读与听写、字体缩放、页面缩放、对比度调节、键盘焦点管理。

### 4.6 部署与合规

- Docker 单容器：FastAPI 同时托管前端构建产物与 API，SPA 回退，前后端同源。
- Render 线上部署，真实 AI 生效；同时提供 `docker-compose` 云服务器方案。
- 隐私政策、用户协议、使用规范、版权说明、关于页、照片隐私提示、注册协议提示齐备。
